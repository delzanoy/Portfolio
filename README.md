# Product design portfolio

A portfolio site for product design and engineering work, built with Next.js, React, and TypeScript.

## Run locally

Requires Node.js and npm.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
```

The project is configured for static export; the build writes the deployable site to `out/`.
